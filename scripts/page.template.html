題材の案件

改札の天井にディスプレイを吊り下げ、そこに付けたカメラの映像を別室のエッジ端末が解析する想定です。駅名、数値、試験データはすべて架空です。顔認証は実行しておらず、人物の位置と判定結果を時系列データとして用意したシミュレーションです。

架空の仕様
舞台あさなぎ線 ひかり台駅(架空)
天井高3.0 m
ディスプレイ下端床から 2.2 m
解像度カメラ、ディスプレイともに 1920×1080
顔認証の有効距離カメラから 2.0〜4.0 m
デモのシナリオ
人物動き表示効果音
A有効距離に入る緑の人型 + チェック印OK 音
B有効距離に入る赤の人型 + バツ印NG 音
C有効距離の外を通過灰色の人型なし

カメラと画面で、人型の位置が一致する

カメラとディスプレイの解像度が同じなので、カメラ映像の座標をそのまま表示に使えます。破線は、人物 A の横位置 x = {{X}} px です。距離は {{D}} m の時点です。通行者と向き合うと左右が逆に見えるため、鏡のように見せたい場合は x 座標を反転します。

13 ツールの実演

画像、音声、動画はすべて CLI の実出力です。掲載したコマンドは、終了コード 0 で成功したものだけです。作業フォルダは build/ で、長いコマンドは途中を省略して表示しています。コピーすると全文を取得できます。

どのツールにも共通する使い方

拡張子で形式が決まる

出力ファイルの拡張子を変えるだけで、書き出す形式を切り替えられます。

コマンドは調べてから使う

commands で一覧を、describe で引数を確認できます。ツールによって名前が少し異なります。

順番に実行して保存する

run は複数のコマンドを順に実行し、最後に保存や書き出しを行います。

AI エージェントから使う

多くのツールは mcp で MCP サーバーとして起動できます。

上書きは止まる

入力と同じファイルへの保存は原則拒否され、--in-place で許可します。

PowerShell の引用符に注意

JSON はシングルクォートで囲むか、スクリプトファイルに分けると安全です。

実行してわかった注意点

各バージョンで今回確認した挙動です。
